AzerothCore Linux portable server - changes (tl;dr)

v0.1 (first working version)
- Portable AzerothCore build (Playerbot fork) + modules: playerbots, autobalance, ale (Lua), ah-bot-plus, dungeon-clear, rndbot-buffs, gm-realmfirst-fix, transmog, individual-progression. Modules pinned in modules.lock.
- Everything runs from one folder: bundled MySQL 8.4, client data, libs. Config lives next to the binaries.
- Core patch: module configs are read from the -c config folder (patches/portable-config-path.patch); bundled OpenSSL legacy provider (needed by the client protocol).
- Admin TUI (acore-admin, Go): start/safe stop, live logs, DB backup/restore (full / player data, import old dumps; the only automatic backup is the install-time master, which the TUI cannot delete), realmlist editor, module toggle + rebuild with undo.
- One-script installer (install.sh): builds in an Ubuntu 22.04 distrobox, assembles the portable folder, first-boot DB setup, accounts from a local file.
- Config overrides (config-overrides/) re-applied to stock configs on every install/rebuild.
- Lua (ALE) scripts: addon<->server messaging layer, Darkmoon ticket rewards from all instance bosses, shop server, creature-cache priming for 3D previews, Bot Manager.
- Addons: AcoreLib (messaging), wotlk_shop (Forgotten Pets/Mounts, Toys, free Services; 3D previews), wotlk_botmanager (companion bots, smart Fill Group).
- Shop catalog generated from the database + client data (reachable-source analysis finds items that cannot be obtained anymore).

v0.2
- Single-file installer: tools/package-installer.sh builds dist/acore-install.sh (self-extracting; downloads cached next to it). Installer can pause so you can edit module settings before the first boot (--no-configure to skip).
- Owner settings file (lua_scripts/acore_settings.lua): shop currency (item or gold) and prices, dungeon reward item (or off), free hearthstone after dungeons, dungeon teleporter NPC, garrisons on/off. Never overwritten by the installer.
- Dungeon teleporter NPC (generic "Chromie", no quests): all dungeons/raids, destinations checked against the game's own exit data; Naxxramas Wrath + Classic 40.
- Garrisons (housing, Northshire Abbey proof of concept): portal, own phase, placeable trainers / auctioneer / banker / guild vault / mailbox, Menagerie (roaming pets), Jukebox NPC; visitors via group; scripts never leave orphan spawns.
- Jukebox addon: ~1000 game tracks with real lengths, favorites, shuffle, repeat; in a garrison the NPC plays music for everyone inside.
- Admin TUI: open module settings folder, build client addon patch archive (zip/tar.gz), custom SQL applied on every start, confs are kept across rebuilds.
- Custom database content lives in custom-sql/ (applied by the TUI on every start), not in core update folders.
- Garrison admin: "Show Removed" / "Show Unsorted" checkboxes (off by default). Players never see Removed or Unsorted items; anything of theirs still placed in those categories is deleted at login.
- Garrison: placed objects that vanish after their open/close animation (self-closing doors) are respawned after the animation; delay comes from the door's own data.
- Admin TUI: quit asks for confirmation and safely stops the servers first; new Accounts tab (add / delete / GM level / password); "Reset to fresh install" (Server tab, key R) restores the install-time master snapshot (backups/fresh).
- Installer: asks which optional components to install (Garrison + Jukebox, Shop, Bot Manager, Timewalking; all on by default; --no-<name> flags, --yes for no questions), an optional server name, and player accounts; creates the master snapshot before any accounts exist.
- Admin TUI (Config tab): [d] detects this machine's LAN address and saves it to the realmlist (local only, no internet lookup); [l] sets localhost (127.0.0.1).
- Garrison placement: the preview now appears about 0.2 s after you stop (the client tells the server the moment you stand still) instead of about 1 s.
Housing experiments: whole buildings (WMO) added to the garrison catalog as Unsorted (admin only).
Garrison: the portal now stands at the Stormwind Mage Tower. Players pick one garrison location (Northshire Abbey or Arathi Shore), optional price in acore_settings.lua (garrison.cost, default free), can abandon it (everything placed is lost) and pick another. Leaving a garrison's area returns you to the Mage Tower. /garrison only opens inside your own garrison; /garrison admin needs GM level 3 (also needed to place Removed/Unsorted items).
Garrison: 'You are leaving your garrison' Leave/Stay prompt; fixed entering a garrison from the Mage Tower (the area check could send you straight back); the radius ring comes back when you re-enter; 71 more props (Unsorted) from the mod-warband-camp prop list.
Garrison code split into 15 parts (garrison_<name>.lua); locations are now data in the world DB (.garrison addloc); instant logout + rested XP inside a garrison; Up/Down in placement mode; safer database handling (no cleanups at load).
Jukebox: works on its own (installer no longer ties it to Garrison); Arathi Shore area set from the radius1-10 teles; .garrison phase + phase checks in the log.
Garrison areas can be any shape (an outline of points, .garrison addpoint); Arathi Shore now follows your radius1-10 points; the radius preview draws the border near you and follows you.
Radius preview: markers keep a fixed height (1.5 yd) above the ground, and above the water surface over water.
Radius preview: over water every marker now hangs at the same height above the (flat) water surface.
Radius preview: markers over deep water no longer jump to the player's height.
Radius preview: one water level per location (also covers water the map data misses), live height report in the log and with .garrison markers.
Garrison: running on after the leave prompt now forces you out (20 yards past the border); Exit Garrison button in the garrison window.
Garrison: leaving the area is now a 5 second on-screen countdown (walk back in to cancel); no more Leave/Stay prompt.
Fixed the Exit Garrison button (its confirm dialog had been removed by mistake); added tools/lint_addons.py.
New garrison location Fenris Isle (gar6, 14-point outline over a lake); border markers handle several water levels in one area; .garrison rename.
Admin TUI: new Server dashboard (status, uptime, characters online, disk), themed layout, spinner/toasts, ? help, clickable tabs, log filter/errors-only/pause, account search + online status. New Debug tab (switch Playerbots/Server/Errors/Auth log files; Playerbots.log off by default; clear mysqld.log, auto-trimmed at start). Debug tab also has two garrison maintenance actions (empty all garrison data; remove data of deleted accounts), each asking about a backup first. Restore, reset, module apply/undo and component-off now ask "create a backup first?" instead of making automatic backups; the install-time master stays the only automatic one and cannot be deleted in the TUI.
Installer: choose "recommended settings" (our tuning: XP x4, 300 playerbots, auction bot active, rates...) or plain AzerothCore defaults (--stock-settings). Portable paths and database settings are always applied. config-overrides/ = required, config-overrides/recommended/ = tuning; the choice is stored in config/settings.conf.
Jukebox: Favorites is its own tab; one Play/Stop button; Shuffle (random songs from the list you are viewing) and Play Random Songs (whole catalog) both grey out the Mode button and Stop turns them off; Mode = Autoplay (default) / Repeat / Off; Next/Prev follow the mode; the song restarts after zooming (the game's zone music cuts it); Add/Remove Favorite button; now-playing panel and a small bar that shows what is playing even when the window is closed or someone else controls the garrison jukebox.
Garrison window: subcategories (name a category Parent > Child, e.g. Holiday > Winter Veil; the category column groups them under an expandable parent; the admin Categories editor accepts the same names).
.garrison (or .garrison help) lists every GM option; unknown options point to it.
Garrison entry: the player is phased first and teleported 0.4 s later (the phase is re-checked and re-applied), so no more seeing/aggroing normal-world mobs on arrival. Logging out inside a garrison saves your position as the portal room, so the next login starts there.
New addon wotlk_minimap (Minimap Drawer): one movable minimap button that opens a drawer with all other minimap icons (not zoom/calendar), plus launchers for Garrison, Jukebox, Bot Manager and Shop. /mmd list | ignore | unignore | reset. Client-only.
